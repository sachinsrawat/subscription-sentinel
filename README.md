# 💳 Subscription Sentinel

### A Smarter Way to Manage Recurring Expenses

Subscription Sentinel is a modern, responsive subscription management dashboard designed to help users track recurring expenses, manage subscriptions, and monitor upcoming payments in one place.

The application provides an interactive dashboard with spending summaries, subscription management, category-based visualizations, and persistent browser storage.

## ✨ Key Features

- **Dashboard Overview:** Monitor monthly spending, active subscriptions, and upcoming payments.
- **Subscription Management:** Add, edit, and delete subscription records.
- **Recurring Expense Tracking:** Track expenses across different billing cycles.
- **Annual Spending Projection:** Estimate yearly subscription expenses.
- **Interactive Charts:** Visualize subscription spending by category.
- **Search and Filtering:** Find subscriptions and filter them by category.
- **Upcoming Payments:** Review upcoming subscription payment dates.
- **Local Data Persistence:** Save subscription information using browser Local Storage.
- **Dark Mode:** Switch between light and dark themes.
- **Responsive Design:** Use the dashboard on desktop, tablet, and mobile devices.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code or another code editor

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sachinsrawat/subscription-sentinel.git
   ```

2. Navigate to the project directory:

   ```bash
   cd subscription-sentinel
   ```

3. Open the project folder in Visual Studio Code.

4. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code to run the application locally.

No backend or database installation is required.

## 💡 How It Works

1. Add subscriptions by entering their details.
2. View monthly expenses and active subscriptions on the dashboard.
3. Monitor estimated annual spending.
4. Explore the category chart to understand spending distribution.
5. Search for subscriptions or filter them by category.
6. Edit or delete subscriptions as needed.
7. Refresh the browser to verify that saved information persists.

## 🔐 Data Storage and Limitations

Subscription information is stored locally in the browser using Local Storage.

- Data is stored in the browser where it was created.
- Data is not automatically synchronized across devices or browsers.
- Clearing browser site data may remove saved subscriptions.
- The application does not process payments or connect directly to subscription providers.
- The Chart.js visualization requires an internet connection when loaded through its CDN.
